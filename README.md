# Conquer the Dungeon — builds

Versões do jogo para Windows. O código-fonte não fica aqui.

## Instalar

1. Abra a [última versão](https://github.com/lipecosta00/conquer-the-dungeon-releases/releases/latest).
2. Baixe o `ConquerTheDungeon-<versão>-windows-portable.zip`.
3. Descompacte e abra `Conquer The Dungeon.exe`.

Depois disso o jogo se atualiza sozinho ao abrir.

## Jogar com amigos

No menu, **Jogar com amigos → Hospedar partida** mostra o seu IP para os
outros digitarem em **Entrar numa partida**. Na mesma rede, use o IP local;
pela internet, usem a mesma VPN (Radmin VPN ou ZeroTier). Na primeira vez, o
Firewall do Windows pede para liberar o jogo: permita em redes privadas.
